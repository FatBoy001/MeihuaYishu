# 梅花易數兩數起卦
一個使用 HTML、CSS、JavaScript 製作的梅花易數兩數起卦工具，可直接部署於 GitHub Pages，無需後端。

## 功能
* 根據兩個數字自動起卦
* 計算上卦、下卦、主卦、動爻、變卦
* 顯示主卦與變卦卦象
* 顯示主卦、變卦、動爻基本解釋
* 顯示主卦與變卦的上下卦象意
* 顯示起卦計算過程
* 支援複製起卦結果

## 起卦規則
* 第一個數字除以 8 取餘數，得到上卦。
* 第二個數字除以 8 取餘數，得到下卦。
* 兩數相加後除以 6 取餘數，得到動爻。
* 將動爻的陰陽互換，得到變卦。
